# 古籍多版本校勘工作台

纯浏览器本地运行的多版本古籍校勘应用：**Vue 3 + TypeScript + Pinia + Vite + WebWorker**。
不接 OCR、不调外部模型、不需要服务端；所有底本、对齐、采用稿、批注与项目包都在浏览器本地生成与保存。

## 一、它解决什么问题

- 同一段话在甲本分成两行、乙本少一句、丙本把一段移到后面——按行号比较会从第一处缺句开始整页错位。本工具先按**篇章/页界与人工锚点分段**，再在段内做码点级序列对齐，缺句只表现为该段内的连续缺口，后续文字不被带偏。
- 直接统一异体字会抹掉需要研究的写法。本工具的**原始底本按 Unicode 码点原样保存**，异体对照与标点忽略只作用于“比较字符”，每个比较字符都带着对应的原文码点区间，一字对多字（合文）也能反查。
- 校勘员在采用稿前加一句话，按字符下标保存的批注会全部挪错。本工具的采用稿字符与批注都使用**稳定字符标识与原文锚点**，插句不影响既有标识；删除承载批注的文字只会让批注进入“待重定位”，绝不自动挂到旁边一句。

## 二、功能与需求对照

| 能力 | 实现位置 |
| --- | --- |
| 原始底本按 Unicode 码点保存，保留页/行/字坐标与 SHA-256 文件指纹 | `src/core/codepoint.ts`、`src/core/hash.ts` |
| 标点忽略 + 异体对照，比较字符维护原文区间，一字对多字不丢反查 | `src/core/normalize.ts` |
| 篇章/页界 + 人工确认锚点分段，段内可配置插入/删除/替换代价的 DP 最小代价对齐 | `src/core/align/dp.ts`、`src/core/align/align.ts` |
| 重复句同分歧义：枚举全部同分方案给校勘员确认，不固定取左侧 | `enumerateOptimalPaths` + 校勘页“同分歧义”弹窗 |
| 长文 WebWorker 分块计算，块间重叠区核验接缝，接缝不一致合并窗口重算 | `src/worker/`、`chunkedAlign` |
| 取消/切换底本后旧回包不覆盖新选择（requestId 单调递增 + 句柄比对） | `src/services/alignmentService.ts`、store `runPair` |
| 连续增删片段的移段候选（内容 LCS 相似度 + 上下文），人工配对，新旧位置均可回查，不宣称版本先后 | `detectMoves/pairRuns`、“移段”页 |
| 三本以上先建参考本对齐列；参考本之外的新增段落二次对齐归组，不消失 | `buildMultiColumns` |
| 采用某本/合成/暂不取舍，每项决定绑定底本字符标识、对齐修订号与理由；机器建议未经确认不进采用稿 | `src/stores/collation.ts`、“取舍与采用稿”页 |
| 采用稿操作记录维护原文锚点；删字使批注待重定位，必须显式重挂 | `src/core/draft.ts` |
| 两份导出包合并：不相交修改自动合入；相反取舍、移动范围重叠、同块改动逐项选择，不允许整份覆盖 | `src/core/merge.ts`、“项目包”页合并弹窗 |
| 新底本到来：重算对齐后逐条标出已确认决定“仍有效/待复核”，旧依据快照保留 | `src/core/recheck.ts`、“底本”页复核表 |
| 可重新导入的项目包 + 带出处采用稿（Markdown）；导入核验正文/对齐/批注一致性，损坏分块拒绝恢复 | `src/core/package.ts`、`src/core/exportAdopted.ts` |
| 虚构样例覆盖异体归一、连续缺句、重复短句歧义、整段迁移、新版本插字，差异全部由输入计算生成 | `src/core/sample.ts` + `tests/sample.test.ts` |

## 三、本地启动

要求 Node.js 22（仓库开发使用 22.14.0）。

```bash
npm install        # 如遇全局缓存权限问题，可加 --cache ./.npm-cache
npm run dev        # 开发服务器，默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 本地预览生产产物，http://localhost:4173
npm run test       # 运行全部单元测试（vitest，38 个用例）
```

### Docker 一键启动

```bash
docker compose up --build -d
# 打开 http://localhost:8080
```

多阶段构建：Node 镜像内 `npm ci && npm run build`，产物交由 nginx 静态托管（含 SPA 回退）。
> 说明：当前交付环境内没有 Docker daemon，镜像构建命令未在本机实际执行；Dockerfile/compose 为标准静态托管配置，应用本身的构建与测试已在本机全部跑通。

### 账号

本应用为纯本地单机工具，**没有登录体系，也不需要测试账号**；打开页面即自动加载内置虚构样例工程。数据保存在浏览器 localStorage，正式交付请使用“项目包”导出/导入文件。

## 四、页面操作与验证路径

1. **底本**页：查看甲/乙/丙/丁四个虚构底本的码点数、比较字符数与 SHA-256 指纹；可导入新底本并查看已确认决定的复核结论。
2. **规范化配置**页：切换标点忽略、调整三种对齐代价与分块参数、维护异体对照表；每次修改都触发重算。
3. **校勘对齐**页：选择对照底本（默认乙本），上下列并排显示；绿色同文、橙色异字、红色缺/增字、紫色同分歧义。鼠标悬停任意字符弹出**原文出处**（页行坐标 + 码点区间 + 是否异体归一）。紫色歧义区点击后在弹窗中逐项选择同分方案；开启“锚点模式”可点选两本字符建立人工锚点。
4. **移段**页：查看丙本“君子食無求飽……”整段迁移候选（相似度、原位置/新位置 token 区间、上下文），人工确认或否决。
5. **取舍与采用稿**页：在参考本对齐列上逐列作出“采用某本/合成/暂不取舍”并填写理由；只有已确认决定进入采用稿。可稿前插句、删块、移动块、给字符加批注；删除被批注文字后批注进入待重定位，需选中新字符显式重挂。
6. **项目包**页：导出可重新导入的 `.json` 项目包、导出带出处的 `.md` 采用稿、导入项目包、做双包合并、立即核验一致性，并可一键下载“损坏示例包”验证拒绝恢复逻辑。

### 内置样例的五种情形（均由计算生成，非预排对照表）

1. **异体归一**：乙本「旹」与甲本「時」归一后匹配（match 而非 sub），悬停可见原字「旹」与码点区间。
2. **连续缺句**：乙本缺「有朋自遠方來」，对齐结果是 6 个连续 gap，其后的「樂」仍与甲本「樂」正确配对。
3. **重复短句歧义**：甲本「溫故而知新」两见、乙本一见，DP 出现同代价分叉，页面紫色歧义区给出多个同分方案。
4. **整段迁移**：丙本把「君子食無求飽……」移到篇末，移段页给出相似度约 94% 的候选，原位置与新位置区间均可回查。
5. **新版本插字**：丁本衍一「時」、「遠方來」作「遠方而來」，衍字以 gapA 进入多版本列，丁本全部 token 均被列或新增段覆盖。

## 五、已实际执行的验证

- `npm run test`：**8 个测试文件、38 个用例全部通过**，覆盖码点/坐标/指纹、规范化反查、DP 代价与同分枚举、取消、分块接缝、移段、样例五类情形、采用稿操作记录与批注重定位、项目包损坏拒绝、双包合并冲突、新底本复核、Pinia 端到端主链路。
- `npm run build`：`vue-tsc --noEmit` 类型检查零错误，Vite 构建成功，WebWorker 独立分包（`alignment.worker-*.js`）。
- `vite preview` 启动后 `curl` 访问首页返回 HTTP 200。
- 损坏检测已被测试固化：篡改底本正文、改动分块区间、破坏整体校验和、非法 JSON 四种情况都会抛出 `CorruptPackageError`，不会假装恢复成功。

## 六、目录结构

```
src/
  core/            纯领域逻辑（不依赖 DOM，Worker 与测试共用）
    codepoint.ts   码点拆分、页行坐标、篇章标记
    hash.ts        SHA-256 指纹、稳定序列化与校验和
    normalize.ts   标点忽略/异体对照与原文区间反查
    align/         DP 引擎、分段、歧义枚举、分块接缝、移段、多版本列
    pipeline.ts    计算管线
    draft.ts       采用稿操作记录与批注锚点
    package.ts     项目包导出/导入/一致性核验/损坏检测
    merge.ts       双包合并与逐项冲突
    recheck.ts     新底本复核
    sample.ts      虚构样例
    exportAdopted.ts 带出处采用稿 Markdown
  worker/          WebWorker 与消息协议
  services/        主线程 Worker 服务（取消与过期回包防护）
  stores/          Pinia 全局状态
  components/      六个页面面板
  ui/              出处查询与文件下载辅助
tests/             vitest 单元与端到端测试
```
